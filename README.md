# VaxReach

VaxReach is a browser-based immunisation follow-up prototype for coordinating vaccination reminders, outreach, and support across health workers, administrators, and families.

## Run the prototype

Open `index.html` in a modern browser. The map uses Leaflet from unpkg, so map features need an internet connection.

## Demo data

The app seeds sample records in the browser and stores changes in local storage. Use only the built-in demo data; do not enter real patient information. This prototype has no production backend, and its vaccination schedule is not clinically verified. Confirm schedules and care decisions with an authorised health professional before real-world use.
